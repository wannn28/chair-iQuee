# chair-iQuee

One-page furniture configurator demo. Rotate a single chair and recolor it with five finishes.

## Stack

Vite, React, TypeScript, React Three Fiber, `@react-three/drei`

## Model

Local Kenney Furniture Kit chair (CC0) at `public/models/chair.glb`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
